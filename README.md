# Закрывающий тег

Проектная работа 4 спринта: адаптивная страница-рефлексия о пути обучения вёрстке.

## Запуск
Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Публикация
В настройках репозитория откройте **Settings → Pages**, выберите рабочую ветку и корневую папку (`/root`). После публикации добавьте полученную ссылку сюда.

Изображения загружаются с Unsplash, поэтому для их отображения требуется подключение к интернету.
